Claude Code plugin

Your journal, one slash away

Install it from inside Claude Code. Then type /dayone to see the commands, or just ask in plain English.

/plugin install dayone --marketplace kachihro/dayone-mcp
📅
/dayone:on-this-day [date]

Memories from today in past years

🔎
/dayone:search <topic>

Tries related words and summarises what it finds

✨
/dayone:reflect [period]

Highlights, themes and mood for any period

🩺
/dayone:setup

Checks everything and tells you what to fix
